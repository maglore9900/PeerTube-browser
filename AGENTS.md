## Agent skills

### Issue tracker

Local markdown: issues in `docs/project/issues/`, feature plans in `docs/project/plans/`, unplanned roadmap items in `docs/project/roadmap.md`. See `docs/project/issue-tracker.md`.

### Triage labels

A `Status:` line per issue with one category (`bug`/`enhancement`) and one state role: the five canonical ones, strings unchanged, plus `complete` for delivered issues, which move to `docs/project/issues/archive/`. See `docs/project/triage-labels.md`.

### Domain docs

Single context: `CONTEXT.md` glossary at the root, ADRs in `docs/project/adr/`. See `docs/project/domain.md`.
